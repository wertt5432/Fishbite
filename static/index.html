    About & 2026 Congressional App Challenge Disclosures

    Purpose: Fish Bite is a private, local scam and link inspector that helps seniors, teenagers, and everyday users evaluate suspicious text messages, emails, and links without transmitting private data to third-party cloud servers.

    Limitation of Liability & Accuracy Disclaimer: Fish Bite is an informational tool only and does not guarantee results. Scammers constantly evolve their tactics, meaning legitimate messages may occasionally be flagged and new scams may go undetected. Users must always think vigilantly and independently verify communications.

    Tools & Open-Source Libraries Used (Section 3 Originality Disclosure):
    • Languages & Web APIs: Python 3, HTML5, CSS3, JavaScript, Browser Web Speech API (window.speechSynthesis), and Clipboard API (navigator.clipboard).
    • Python Standard Library: urllib.parse (URL/domain decomposition) and re (regular expression matching).
    • Open-Source Libraries (requirements.txt): FastAPI (MIT License — web API routes), Starlette & Pydantic (BSD/MIT — static file serving & data handling under FastAPI), Uvicorn (BSD License — ASGI web server), Pytest (MIT License — unit testing), and HTTPX (BSD License — API test client).
